# LLM Hallucination Verification System

## 📌 Project Overview

The **LLM Hallucination Verification System** is a web-based application designed to verify factual claims in text and identify potentially 
unsupported or incorrect information in answers generated by Large Language Models (LLMs).

Large Language Models can sometimes generate information that sounds convincing but is inaccurate or unsupported by available evidence. 
This project addresses that problem by checking claims against a knowledge graph and classifying verification results into different categories.

The system allows users to submit text for verification, examine the available supporting evidence, and review the results through a web interface.

## 🎯 Objectives

- Identify factual claims that may contain hallucinations.
- Verify claims against information available in a knowledge graph.
- Distinguish supported claims from unverified or potentially incorrect claims.
- Visualize relationships between entities and facts using a knowledge graph.
- Maintain a history of previous verification activities.
- Evaluate a traditional machine-learning baseline for comparison with the knowledge-graph-based approach.

## ✨ Key Features

- **Text Verification:** Submit text or LLM-generated answers for factual verification.
- **Knowledge Graph:** Represent facts and relationships as connected nodes and edges.
- **Claim Classification:** Categorize verification results as supported, unverified, or hallucination suspected.
- **Evidence-Based Analysis:** Examine available knowledge-graph information to identify evidence relevant to submitted claims.
- **Graph Visualization:** Explore knowledge-graph relationships through interactive visualizations.
- **User Authentication:** Register and log in to the application.
- **Verification History:** Store and review previous verification results.
- **Machine-Learning Baseline:** Use TF-IDF and Logistic Regression as a baseline for text classification and performance comparison.
